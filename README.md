# Book_Recommendation_System
# 📚 Book Recommendation System

A sample Book Recommendation System built using **Popularity-Based Filtering** and **Collaborative Filtering** techniques. This project showcases how to build a basic recommender system using Python and Flask, with a clean web interface and insightful data processing.

---

## 🔧 Technologies Used

- **Python**  
- **PyCharm** (IDE)  
- **Flask** (Web Framework)  
- **HTML & CSS** (Frontend)  
- **Jupyter Notebook** (Data Cleaning & Analysis)  
- **Scikit-learn** (Cosine Similarity & ML Utilities)

---

## 📊 Data Preprocessing & Analysis

The dataset was cleaned and analyzed in **Jupyter Notebook**. Key tasks included:

- Removing missing or irrelevant values  
- Filtering out less-rated books and inactive users  
- Creating a user-item interaction matrix  
- Exploring rating trends and distributions

This step ensured the model was trained on meaningful, high-quality data.

---

## 🧠 Recommendation Algorithms

### 1. 📈 Popularity-Based Filtering
- Recommends books that are most popular based on number of ratings or average score.
- Suitable for users without any prior interaction history (cold-start users).
- Simple but effective for general suggestions.

### 2. 👥 Collaborative Filtering (User-User)
- Uses **cosine similarity** from `sklearn.metrics.pairwise` to compare users.
- Identifies similar users and recommends books based on what their peers liked.
- More personalized than popularity-based filtering.

---

## 🖥️ Web Interface

A basic web interface was built using **Flask**, with simple **HTML & CSS** for the frontend:

- Users can input a book title or view top recommendations.
- Flask handles routes and integrates backend logic with the UI.
- Lightweight and easy to run locally.
